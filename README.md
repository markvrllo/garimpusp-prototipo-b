# GarimpUSP · Protótipo B ("Procura-se")

Protótipo de interação do **GarimpUSP**, plataforma de compra, venda e troca entre estudantes da USP, desenvolvido para a disciplina PRG0005 · Fundamentos em Empreendedorismo (2026), Entrega 5.

**Acesse:** [https://marcosreballo-hub.github.io/garimpusp-prototipo-b/](https://markvrllo.github.io/garimpusp-prototipo-b/)

## O que esta versão mostra

Nesta versão o fluxo é orientado à demanda: quem precisa do item publica um pedido, e quem tem o item recebe o alerta e faz a oferta.

1. **Publicar pedido**: o comprador informa o item, até quanto paga, até quando precisa e o ponto de entrega no campus.
2. **Alerta para quem tem**: vendedores do campus veem o pedido e enviam uma oferta.
3. **Comparar ofertas**: preço, estado do item e reputação (nota, nº de negociações e % de compromissos cumpridos).
4. **Reserva de 48 h e chat protegido**: o item fica reservado e o telefone só é liberado após o aceite das duas partes.
5. **Confirmar e avaliar**: as duas partes se avaliam; ausência sem aviso conta contra a reputação.

Use os passos à esquerda (ou os botões dentro do celular) para navegar. Cada tela também tem um endereço próprio, por exemplo `#ofertas` ou `#reserva`.

## Observações

- Protótipo de fidelidade média: não há banco de dados, login real nem pagamento.
- Nomes, valores e anúncios são fictícios. Persona: Lucas Silveira (ICMC, campus São Carlos).
- O protótipo não foi testado com usuários.
